# CodeAlpha Social Media Platform

A full-stack Social Media Platform built using the MERN Stack as part of the CodeAlpha Internship.

## 🚀 Features

- User Authentication (Signup/Login)
- Create, Edit & Delete Posts
- Upload Images with Cloudinary
- Like & Comment on Posts
- User Profile
- Responsive Design

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- Cloudinary
- Multer

## 📂 Project Structure

```
Code Alpha/
├── client/
└── server/
```

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/anushkasoni0709-netizen/CodeAlpha-Social-Media.git
```

### Backend

```bash
cd server
npm install
npm start
```

### Frontend

```bash
cd client
npm install
npm run dev
```

## 🔑 Environment Variables

Create a `.env` file inside the `server` folder:

```env
MONGO_URI=your_mongodb_connection_string
CLOUD_NAME=your_cloudinary_cloud_name
API_KEY=your_cloudinary_api_key
API_SECRET=your_cloudinary_api_secret
```
